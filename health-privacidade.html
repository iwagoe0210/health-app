Health — Política de Privacidade

Última atualização: 07/10/2026

O Health é um assistente pessoal de uso exclusivo e privado de Renan Iwagoe Castilho (Personalize BR / RIC Infotech). Não é um serviço aberto ao público: apenas o próprio titular entra e usa o aplicativo.

Quais dados o Health acessa

  • Gmail (somente leitura): remetente, assunto e trecho dos e-mails recentes, para classificar em Ação, Contas a pagar, Informativo e Ruído. O Health nunca envia, responde, apaga ou altera e-mails.
  • Google Agenda: leitura dos compromissos e criação de eventos apenas em uma agenda chamada "Health", sempre após confirmação do titular.
  • Oura: dados de sono, prontidão, atividade e frequência cardíaca do titular.
  • Dados informados pelo titular: notas pessoais, medições de pressão e registros de remédio.

Como os dados são usados

Somente para mostrar informações ao titular, montar o resumo diário e responder a perguntas dele. Os dados não são vendidos, não são usados para publicidade e não são compartilhados com terceiros para outros fins.

Onde ficam e com quem passam

  • Armazenamento: banco de dados Supabase do titular, com acesso restrito ao e-mail dele.
  • Trechos de e-mails, agenda e dados de saúde são enviados à API da Anthropic (Claude) apenas para classificar e resumir.
  • Textos a serem falados são enviados ao serviço de voz do Google Cloud para gerar o áudio.

Uso de dados de APIs do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Direitos e contato

O titular pode revogar o acesso a qualquer momento em myaccount.google.com/permissions e apagar seus dados no próprio aplicativo. Contato: personalizebrdtf@gmail.com.
